# Shared navigation for staff

The approved [desktop rail](https://doop.design/c/xH-4xV7kGK?frame=gDOrJNUuQK) needs to move the page as it opens. An overlay would cover the first column of the current page. The rail therefore occupies a column in the existing flex layout. Its links keep their accessible names at both widths. Pointer hover and keyboard focus can each hold it open. Escape clears both without moving focus.

The [phone menu](https://doop.design/c/xH-4xV7kGK?frame=FTr3sdPWhr) uses the same links and role conditions. While it is open, the content behind it is inert. The menu closes when the route or desktop breakpoint changes. The navigation ships Inter 4.1 under the SIL Open Font License to keep the approved typeface available offline. Its license is in `apps/web/public/fonts/OFL-inter.txt`.
